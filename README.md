# 红线车库 REDLINE GARAGE

攒车、调校、烧胎、冲线——一条直线见真章的沙盒直线加速赛。

- 车库里自由拼装：车架 / 引擎 / 变速箱 / 轮胎 / 氮气……想怼什么怼什么
- 每个零件都能调参数：马力、齿比、胎压、氮气时长
- 点火 → 圣诞树倒数 → 油门到底，看 0-100、四分之一英里、尾速一个个破纪录

## 技术栈

Next.js 14 App Router · React Three Fiber · @react-three/rapier@1.5.0（真物理）· PBR 渲染 · Vercel
